# ScreenBot · 截图模板匹配自动点击工具

Windows 桌面自动化小工具：用 OpenCV 模板匹配在你的屏幕上找“按钮图片”，找到就模拟鼠标点击。全部本地运行，不联网。

## 快速开始（开发模式）

```bash
cd screenbot
pip install -r requirements.txt
python main.py
```

## 打包成 exe

```bash
build.bat        # 产物在 dist\ScreenBot.exe
```

exe 可拷贝到任意 Windows 机器直接双击运行；`templates\`（模板图片）和 `config\`（规则）会生成在 exe 同目录。

## 运行模式

- **优先级模式（默认，适合游戏流程）**：每 N 秒（默认 10s，可调）截一次全屏，按列表**从上到下**逐条检查“指定区域是否出现指定图案”，**命中第一条就点击并结束本轮**；全部不中则等待下一轮。列表顺序即优先级，用“上移/下移”调整。适合“开始/游戏中/结束”三个阶段共存于一张规则表：把高优先级判定（如结算弹窗）放最上面。
- **独立模式**：每条规则按自己的 interval 独立轮询，互不影响，各带冷却与点击上限。

## 窗口模式

工具栏勾选“窗口模式”并填窗口标题（如 `明日方舟`）后，程序每轮只截取**游戏窗口**画面，规则的区域、预点击坐标都按**窗口左上角为原点**保存。窗口在桌面上随便挪，规则不会失效；但游戏窗口**尺寸/分辨率改变后模板需重做**。制作规则前请先开启窗口模式，框选和抓坐标会自动换算成窗口相对值。未找到窗口时该轮跳过并在日志提示。

## 模拟器模式（ADB，最彻底的后台）

勾选“模拟器模式”并填 ADB 地址（默认 `127.0.0.1:7555`）：截屏走 `adb exec-out screencap -p`（安卓真实画面，与模拟器窗口状态无关），点击/滚动走 `adb shell input tap/swipe`（注入安卓输入流）。**Windows 鼠标键盘完全不受影响，无需管理员权限**。模拟器分辨率设为 1280×720 即可复用全部模板。常见 ADB 端口：MuMu `7555`、雷电 `5555`、夜神 `62001`、BlueStacks `5555`（以各模拟器设置页为准，需开启 ADB/调试）。需要系统 PATH 里有 adb（Android platform-tools），或在设置里把 `adb_exe` 改成完整路径。

## 后台模式（不抢鼠标）

窗口模式下勾选“后台模式”：截图改用 **PrintWindow**（直接渲染窗口画面，游戏可在后台甚至最小化），点击/滚轮改用 **PostMessage** 向窗口投递鼠标消息——**不移动真实鼠标、不抢焦点**，你可以边挂机边用电脑。PrintWindow 拿不到画面时（个别 GPU 渲染返回黑帧）自动回退为屏幕截取。仍需管理员权限运行（游戏提权时普通进程无法向其发消息）。若后台模式下匹配全部失效，说明该客户端画面抓不到，取消勾选回前台模式即可。

## 组合动作（预点击序列）

规则命中模板后，可以先按**固定屏幕坐标**依次点击若干次（每步间隔“预点击间隔”秒），最后再执行主动作。适合“先买卡牌（点同一位置两次）→ 再点准备就绪”这类顺序操作。坐标可在规则编辑里用“抓取鼠标位置…”按钮记录：点按钮后 2.5 秒内把鼠标移到游戏里的目标处即可自动填入。

## 暗格选择（按底色挑未选项）

规则可配“暗格坐标”列表：模板命中后，依次采样每个坐标周围 20×20 像素的亮度，**点击第一个偏暗（未选择）的格子**，全部偏亮则不动作。适合“6 选 1 奖励，黑底=未选、高亮=已选”这类界面。配合“出现一次只点一次”复选框：点过一次后该规则保持沉默，直到触发模板从画面消失才重新武装，防止把 6 个全点一遍。

## 使用流程

1. **新增** 规则 → 填名称
2. 点 **框选截图…** → 在屏幕上拖框选中目标按钮 → 自动存为模板
3. 设置 **匹配阈值**（默认 0.85；找不到就降到 0.8/0.75）
4. 设置动作（左键/右键/双击/滚轮下滑/仅提醒）、偏移、扫描间隔、冷却、点击上限。滚轮下滑用于列表翻找：匹配位置+偏移=滚动落点，“滚轮格数”=滚动幅度
5. 点 **测试匹配** 确认当前屏幕能命中，保存
6. **▶ 启动**（或按 F8）。运行期间按 **F9** 停止；把鼠标甩到屏幕 **左上角** 可紧急中断 pyautogui

## 规则字段说明

| 字段 | 说明 |
|---|---|
| 阈值 | 0~1，越高越严格。界面外观变了（主题/缩放变化）会失配 |
| 区域 | 全屏或框选一块子区域；限定区域能显著提速并避免误点 |
| 偏移 | 相对模板中心的 dx/dy，用于点按钮角落/关闭小叉 |
| 冷却 | 每次命中点击后的等待秒数，防止目标没消失时反复连点 |
| 上限 | 达到次数后该规则自动停（0 = 一直循环） |

## 常见问题

- **明明屏幕上就有，却匹配不到？** 降阈值；检查是否系统缩放导致模板与屏幕渲染比例不同——请在当前缩放下重新框选。
- **点击位置偏？** 程序启动时已设置 DPI 感知；若仍在缩放非 100% 的多屏环境偏移，检查是否选择了副屏区域（v1 仅支持主屏）。
- **误点？** 用“区域”把搜索圈小，或用“仅提醒”先观察日志。
